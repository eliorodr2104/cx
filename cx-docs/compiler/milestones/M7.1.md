# M7.1: Field defaults that read earlier fields

Status: **Completed** (implemented and verified in this checkout).

Baseline: the pinned checkout recorded in the [M0 record](M0.md).

A follow-up to [M4e](M4e.md), whose defaults could not mention another field,
and to [M7b](M7b.md), which fixed what an initializer may read.

```c
struct Size {
  int width
  int height = width * 2
  const int area = width * height
}

Size a = Size(width: 3)              // height 6, area 18
Size b = Size(width: 2, height: 5)   // area 10

struct Grid {
  int cols = 4
  int rows = cols + 1                // an earlier defaulted field
  int cells
  init(int extra) { cells = rows * cols + extra }
}
```

## The rule

A default may read an earlier field that holds a value when the defaults are
applied:

- one with a default of its own;
- in a type without a custom initializer, any earlier field, because generated
  construction is given every field without a default.

In a type with a custom initializer, a field without a default is written by the
initializer, after the defaults, so reading it is an error that says so. A
default that reads itself or a later field is an error too.

## Semantics

- **Order.** Defaults that read fields are applied after the others, in
  declaration order, as assignments to the object being built; C leaves the
  order of a braced list's elements unspecified, and each value, such as a
  `next()` given to construction, is computed once.
- **Fields a default reads** are named directly, as inside a method; they win
  over a declaration outside the record, and a library function of that name is
  not implicitly declared.
- **`const` and resource fields** are initialized by that assignment.
- **Braces** cannot apply such a default: a braced list gives the field, or the
  value is constructed.
- **Generated construction** with such a default runs code, so it appears only
  in a function, as a construction through an initializer does.
- **Arrays** cannot have a default that reads fields; C cannot assign them.
- **Nested values.** A member left to its own defaults, and each element of an
  array of them in every dimension, applies the defaults that read fields too, at its place in the
  object.
- **Anonymous members** are read by name, and a default inside one reads the
  enclosing fields. A member whose type starts out entirely defaulted holds a
  value before an initializer runs, so a default may read it.

## Representation

A field named in a default is a reference to the `FieldDecl`, which no code
evaluates. Each construction rebuilds the default over its own `__cx_object`
with a `TreeTransform`, so the default is shared and the objects are not. A
generated construction with such a default becomes a statement expression, like
one through an initializer, and `-ast-print` writes it back as
`Size(width: 3)`, leaving out the fields it assigns.

## Permitted baseline C modes

Every C/GNU standard, as in M0.

## Implementation

| Area | Change |
| --- | --- |
| `clang/lib/Parse/ParseDecl.cpp` | the defaulted field is in scope while its default is parsed |
| `clang/lib/Sema/SemaCx.cpp` | field references, the rule at record completion, the rebuild and the ordered assignments in both constructions |
| `clang/lib/Sema/SemaExpr.cpp`, `SemaInit.cpp`, `SemaDecl.cpp` | name lookup, `const` stores into the built object, braced lists |
| `clang/lib/CodeGen/CGCx.cpp` | a resource store into the built object destroys nothing |
| `clang/lib/AST/StmtPrinter.cpp` | constructions with assigned defaults |

## Evidence

- The full Clang lit suite passes, with the known deadlocking
  `Index/crash-recovery-modules.m` filtered out.
- The IR of `field-defaults-reads.c` is identical after `-E` and after
  `-ast-print`.

## Tests

- **`field-defaults-reads.c`**, as GNU17 and GNU89, then as IR, after `-E` and
  after `-ast-print`: generated construction reading given and defaulted
  fields, a `const` field, a given value evaluated once, and a custom
  initializer reading defaulted fields.
- **`field-defaults-reads-errors.c`**: itself, a later field, a field the
  initializer sets, an array, file scope, and braces.
- **`field-defaults-reads-pch.c`**: through a PCH.
- **`field-defaults-reads.c`** also builds, at `-O1`, a value with a nested
  member, an array and an array of arrays of them, an anonymous union and an anonymous struct, and
  checks the folded result.
