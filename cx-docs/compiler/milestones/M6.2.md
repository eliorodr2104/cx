# M6.2: Enum and recovery hardening

Status: **Completed** (implemented and verified in this checkout).

Baseline: the pinned checkout recorded in the [M0 record](M0.md).

A hardening pass that closes three limitations left by [M6c](M6c.md),
[M6.1](M6.1.md), [M6d](M6d.md) and [M5b](M5b.md).

## Payload elements are destinations

```c
enum Wrap {
  case color(Color c)
  case access(Perm p, Color c)
  case corner((int, Color) at)
}
Wrap a = .color(.green)
Wrap b = .access([.read, .write], .blue)
Wrap c = .corner((2, .green))
```

Each argument of a payload construction takes the type of its payload element,
as a function argument takes its parameter's: `.case`, option set literals,
tuple literals and nested payloads find their type there. Labels follow the
tuple rules, so the element is always the one at that position.

`-ast-print` of a payload with one element whose type is a tuple printed the
tuple's elements as the payload's; it now prints the tuple.

## No jump into a clause

A clause of a Cx switch is entered only through its case, which binds its
payload and never falls through. A `goto` into a clause, from outside the switch
or from another clause, is an error ("jump enters a clause of a Cx switch").
Jumps within a clause and out of one are unchanged, and so is every C switch.

## Recovery stops at a line break

After a syntax or semantic error, the parser skips to a point where it can go on,
usually the next `;`. Without semicolons the next `;` could be past the end of
the function, so every later error in it was lost. In Cx, a skip that would stop
at a `;` also stops at a line break, outside parentheses and brackets, where C
breaks lines freely. When the skip starts at the beginning of a line with a token
that begins a statement, it stops at once; it does so only once at each place,
so the parser always makes progress.

## Permitted baseline C modes

Every C/GNU standard, as in M0. Each change is limited to Cx syntax or Cx mode.

## Evidence

- The full Clang lit suite passes, with the known deadlocking
  `Index/crash-recovery-modules.m` filtered out.
- The IR of `enums-contexts.c` is identical after `-ast-print`.

## Tests

- **`enums-contexts.c`**: payload arguments that are cases, option sets, a
  nested payload, a compound literal, a tuple, and labelled.
- **`switch-errors.c`**: a `goto` into a clause from outside and from another
  clause; a jump within a clause; a C switch.
- **`recovery.c`**: consecutive errors on consecutive lines, and one in the next
  function. `init-definite-errors.c` no longer needs a `;` after a failing
  initializer.

## Known limitations

- **`.case == value`** still needs the enum on the left; it is never needed in
  practice.
